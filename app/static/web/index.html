JARVIS is a voice assistant for Windows. It answers questions, carries out commands in milliseconds and stops to ask before anything it can't undo. It runs on your machine, with free or fully local models.

Open the console Set it up in ten minutes

Questions never turn into actions.

JARVIS sorts every sentence before it does anything. A question only gets tools that read, so “How do I reboot my router?” gets an explanation and never a reboot.

  • Checked on every build. 120 everyday questions run against a model that tries to restart, kill and send. None of them may act.
  • One door for every action. Volume, files, apps, messages and power all pass through the same safety gateway, which previews, asks, logs and can undo.
  • A real off switch. Say “emergency stop” or press Stop everything. All automation halts and waiting actions are cleared until you resume.

Deleted files go to the Recycle Bin. Shutdowns wait 30 seconds and “cancel shutdown” stops them. Every decision is written to the activity log.

How a command travels

  1. Hear

    A wake word, voice detection and faster-whisper turn speech into text on your PC.

  2. Route

    About 70 exact sentence patterns catch everyday commands in about a millisecond. Everything else goes to a language model with only the tools that fit.

  3. Check

    The safety gateway sets the risk, writes a preview, asks when it must, and honours dry run and the stop switch.

  4. Act

    Windows UI Automation first, then the keyboard, then the mouse; reading the screen with vision only as a last resort.

  5. Reply

    Words stream as they are written, and the voice starts speaking at the first sentence.

With private mode on, anything read from your files or your screen is sent only to a local model.

Claude Desktop, Cursor and other MCP apps can use JARVIS as a tool, but they can never approve their own risky actions.

Set it up in ten minutes

You need Windows 10 or 11, Python 3.12 or newer, and either one free API key (Gemini or Groq) or Ollama for fully offline use.

  1. Get the code and open its folder.

    git clone https://github.com/upeshchowdary/jarvis-brain-os.git
    cd jarvis-brain-os

  2. Create an environment and install everything.

    python -m venv .venv
    .venv\Scripts\activate
    pip install -e ".[all]"

  3. Copy the settings file, then add one key to .env, for example GEMINI_API_KEY.

    copy .env.example .env

  4. Start JARVIS. The console opens and asks for the token printed in the terminal.

    python jarvis.py --open --voice

JARVIS

Runs on 127.0.0.1 and answers only to your token.
